# Sparkle Journey: VR+AI Rehabilitation System for Children with Autism Spectrum Disorder  
A VR+AI-Based Rehabilitation & Therapy System for Children with ASD  

## Project Overview  
Addressing the pain points of traditional autism intervention—limited training scenarios, scarce professional resources, and challenges in personalized therapy—Spark Together delivers a full-cycle rehabilitation solution centered on **VR+AI+network collaboration**. Built with Unity Engine, the system creates immersive virtual training environments combined with AI companionship and multi-terminal synergy. It provides step-by-step training for children with ASD, from sensory adaptation to social practice, while connecting doctors, families, and special education schools to form a collaborative rehabilitation ecosystem, empowering children to enhance social communication and independent living skills through technology.  

## Core Features  
### 1. Progressive VR Rehabilitation Scenarios  
Based on the TEACCH structured teaching method, four hierarchical virtual spaces are designed to meet the needs of different rehabilitation stages:  
- **Free Space**: A low-stimulation environment to help children familiarize themselves with VR interactions and build a sense of security.  
- **Game Space**: Fun tasks (puzzle challenges, rhythm tapping) to improve attention and sensory integration abilities.  
- **Social Space**: Simulates real-life scenarios (supermarket shopping, classroom interactions) with high-precision modeling to teach basic social rules.  
- **Interactive Space**: Supports real-time multi-user collaboration (e.g., joint classroom organization) to train complex social response skills.  

### 2. AI Rehabilitation Companion Agent  
- Integrates the DeepSeek large model to provide emotional companionship and personalized guidance.  
- Enables multi-modal interaction: Emotion recognition via Pico4 Pro facial tracking, and voice command understanding through Funasr speech recognition.  
- Dynamically adjusts interaction strategies, offers real-time encouragement and behavior correction, and enhances training engagement.  

### 3. Multi-Terminal Collaborative Services  
- **VR Terminal**: Core training scenarios (compatible with Pico4 Pro devices).  
- **Smart Hardware**: 3D-printed AI companion toys for offline emotional support.  
- **Mobile/Tablet Terminal**: Monitoring app for parents/teachers to remotely view training data and adjust intervention plans.  

### 4. Data Security & Collaboration  
- Medical privacy encryption to ensure secure storage of training data.  
- Supports real-time multi-user online interaction, allowing therapists to participate in guidance remotely.  

## Technology Stack  
### Core Development Tools  
- Engine: Unity (VR scene construction & interaction development)  
- Modeling & Rendering: Maya (topology optimization), Blender (texture baking), Hunyuan 3D AI (rapid modeling)  
- Version Control: Git (team collaborative delivery)  

### Key Technology Integrations  
- VR Interaction: Pico4 Pro facial tracking, Unity Shader Graph rendering optimization  
- AI Capabilities: DeepSeek large model (intelligent companionship), Funasr speech recognition, Baidu Cloud TTS/ASR  
- Network Collaboration: Real-time multi-user networking, cross-platform data synchronization  
- Hardware Adaptation: 3D-printed AI companion toys, mobile monitoring terminal compatibility  

## Installation & Usage  
### System Requirements  
- VR Device: Pico4 Pro (supports facial tracking)  
- Operating Environment: Windows 10+ (VR terminal), Android/iOS (mobile monitoring terminal)  
- Hardware Configuration: VR terminal recommends GTX 1660 or higher graphics card for smooth scene operation  

### Quick Start  
1. Clone the repository: `git clone [Repository URL]`  
2. Import the Unity project (Unity 2021.3+) and install dependent plugins (VR SDK, AI interface SDK).  
3. Configure VR device connection and calibrate facial tracking & voice interaction functions.  
4. Install the mobile monitoring app: Scan the QR code in the project or download from the app store.  
5. After launching the system, select the appropriate VR training scenario based on the child’s rehabilitation stage.
