# Sparkle Journey：面向自闭症谱系障碍儿童的 VR+AI 康复系统

[English (primary)](README.md) | **简体中文**

面向 ASD 儿童的 VR+AI 康复与训练系统。

## 项目概述

项目围绕传统自闭症干预中训练场景有限、专业资源不足和个性化训练困难等问题，采用 **VR+AI+网络协作** 的方案。系统使用 Unity 构建沉浸式训练环境，结合 AI 陪伴与多终端协作，设计从感官适应到社交实践的分步训练，并连接医生、家庭与特殊教育学校。

## 核心功能

### 1. 渐进式 VR 训练场景

参考 TEACCH 结构化教学方法，设计四类虚拟空间：

- **自由空间：**低刺激环境，帮助儿童熟悉 VR 交互并建立安全感。
- **游戏空间：**拼图、节奏点击等任务，用于注意与感觉统合训练。
- **社交空间：**模拟超市购物、课堂互动等情境，用于学习基本社交规则。
- **互动空间：**多人实时协作任务，例如共同整理教室，用于练习复杂社交反应。

### 2. AI 训练陪伴智能体

- 集成 DeepSeek，提供情感陪伴与个性化引导。
- 使用 Pico4 Pro 面部追踪进行表情识别，使用 Funasr 理解语音指令。
- 动态调整交互策略，提供鼓励和行为反馈。

### 3. 多终端协作

- **VR 终端：**核心训练场景，面向 Pico4 Pro。
- **智能硬件：**3D 打印 AI 陪伴玩具，用于线下陪伴。
- **移动/平板终端：**供家长和教师查看训练数据、调整干预计划的监测应用。

### 4. 数据安全与协作

- 原项目说明包含训练数据的隐私加密与安全存储。
- 支持多人实时在线互动，供治疗师远程参与引导。

## 技术栈

### 开发工具

- Unity：VR 场景与交互开发。
- Maya：拓扑优化；Blender：纹理烘焙；混元 3D AI：快速建模。
- Git：团队版本协作。

### 集成技术

- Pico4 Pro 面部追踪与 Unity Shader Graph。
- DeepSeek、Funasr、百度云 TTS/ASR。
- 多人实时网络和跨平台数据同步。
- 3D 打印陪伴玩具与移动监测终端。

## 安装与使用

### 系统要求

- VR 设备：Pico4 Pro，支持面部追踪。
- 运行环境：Windows 10+（VR）；Android/iOS（移动监测终端）。
- 原文推荐 GTX 1660 或更高显卡用于 VR 终端。

### 快速开始

1. 克隆仓库：`git clone [Repository URL]`。
2. 在 Unity 2021.3+ 中导入项目，安装 VR SDK 和 AI 接口 SDK 等依赖插件。
3. 配置 VR 设备连接，校准面部追踪和语音交互。
4. 原文移动监测应用安装方式为扫描项目二维码或从应用商店下载；原 README 未提供具体链接。
5. 启动后选择相应 VR 训练场景。

## 项目特点

1. **个性化干预设计：**智能体分析行为数据并调整训练计划。
2. **低门槛适配：**通过场景渲染优化面向中低端设备。
3. **场景覆盖：**结合虚拟训练与线下陪伴。
4. **协作：**连接医生、家庭和学校。
